How to read this report

↓Lower is better. ↑Higher is better. =Should equal the target shown (for example zero). Attributes without an arrow give context only. In the table the best value of each row is shaded.

Under every attribute you find what we are trying to achieve. The numbers are computed the same way for every run, from its session transcript where one exists on this machine and from its run-log.json otherwise.

Human waiting is excluded everywhere. Agent time is wall time minus every wait for a human. A wait over one hour also makes the prompt cache expire, so the next call rewrites the whole context; that rebuild is a cost of the wait and is removed from the cost shown. The raw numbers are in the table too, so nothing is hidden.

Marks after a value: † estimated, ‡ taken from a run summary or another file (hover for the source). “–” means the run did not record it.

Environment

Why it matters: harness version, effort, permission mode and machine all change cost and speed. Operator, machine, plan and permission mode come from run-config.md; the rest is read from the transcripts and the host at the end of the run.

Trust in the measurement

The cost check compares our calculation from the transcript with the cost the harness recorded itself (the usage panel's number). Within 1.5 % the numbers can be trusted.
